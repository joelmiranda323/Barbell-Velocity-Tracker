# Barbell-Velocity-Tracker
A project for made for powerlifters. Current code uses SparkFun libraries located here: https://www.sparkfun.com/sparkfun-6dof-imu-breakout-lsm6dsv16x-qwiic.html?srsltid=AU7gw4VC8qrSFRmHvV7l3Rxvnd4g0NhEervoqQswz7ra1D_DgIDKpaeS

In terms of code, I want to translate this high-level code to lower-level register reads and writes. 
As for hardware, this project is currently using the XIAO ESP32-S3 and the SparkFun lsm6dsv16x breakout and will later be developed on to a custom PCB.
