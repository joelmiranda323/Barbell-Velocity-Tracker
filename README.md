# Barbell-Velocity-Tracker
A project for made for powerlifters.

In terms of code, I want to translate this high-level code to lower-level register reads and writes. 
As for hardware, this project is currently using the XIAO ESP32-S3 and the SparkFun lsm6dsv16x IMU breakout and will later be developed on to a custom PCB.

A testbench example using 3 servo motors will later be developed to better understand the gyroscope on the IMU.
